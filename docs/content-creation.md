# 内容创作指南

> 用 AI 帮你写文章、拍视频、做图片，轻松创作内容

## 1. 创作前的准备

### 1.1 收集你的素材

在创作之前，先把你想分享的东西整理出来：

**问自己 5 个问题：**

1. 我最想让别人知道的一件事是什么？
2. 我经常被人问什么问题？
3. 我做过的最骄傲的一件事是什么？
4. 我踩过的最大的坑是什么？
5. 我每天都在做的一件事是什么？

**把这些答案记下来，这就是你的内容素材库。**

### 1.2 用豆包帮你整理素材

对着豆包说：
> "帮我把[你的经验/故事]整理成几个要点，每条不超过 50 字。"

## 2. 文字内容创作

### 2.1 朋友圈文案（最简单）

**用豆包生成：**

对着麦克风说：
> "帮我写一条朋友圈，分享[你的主题]，要：
> - 字数 100-200 字
> - 语气亲切自然，像和邻居聊天
> - 有一个小故事或细节
> - 最后有一个互动问题"

**示例：**
> "帮我写一条朋友圈，分享我每天早上散步养生的经验，语气要像和邻居聊天。"

### 2.2 长文章（公众号/头条）

**用豆包生成：**

> "帮我写一篇 [800] 字的文章，主题是 [你的主题]，要：
> - 开头用一个故事引入
> - 中间有 3 个实用建议
> - 结尾有一个行动号召
> - 语气温暖、有代入感"

### 2.3 标题创作

**好标题的公式：**

| 类型 | 公式 | 示例 |
|------|------|------|
| 数字型 | 数字 + 好处 | "50岁以后，我坚持做这3件事" |
| 故事型 | 场景 + 转折 | "我以为退休会很无聊，没想到..." |
| 问题型 | 痛点 + 解决 | "总失眠？试试我的方法" |
| 对比型 | 过去 vs 现在 | "以前不懂养生，现在每天坚持" |

**让豆包帮你起标题：**
> "帮我给 [主题] 起 5 个吸引人的标题，要有趣、有悬念。"

## 3. 视频内容创作

### 3.1 口播脚本（对着镜头说）

**用豆包生成：**

> "帮我写一段 [60] 秒的口播脚本，主题是 [你的主题]，要：
> - 第一句：抓住注意力（问问题/说惊人数据）
> - 中间：分享 3 个要点
> - 最后：号召大家互动

**示例输出：**
```
大家好，我是王阿姨，今年65岁。

你有没有这样的烦恼：每天晚上睡不着，白天没精神？

今天我和大家分享3个我坚持了10年的养生习惯：

第一，早睡早起，晚上10点前睡觉。
第二，晚饭后散步半小时。
第三，睡前泡脚，水温40度左右。

你也试试这些方法，如果有用，在评论区告诉我。
```

### 3.2 视频分镜头脚本

**用豆包生成：**

> "帮我写一个 [3] 分钟的视频分镜头脚本，主题是 [你的主题]，包含：
> - 每个镜头的画面描述
> - 对应的台词
> - 预计时长

### 3.3 拍摄小技巧

**不需要专业设备：**

| 设备 | 要求 |
|------|------|
| 手机 | 光线充足、镜头干净 |
| 支架 | 淘宝 30 块钱的手机支架 |
| 麦克风 | 如果环境嘈杂，可以用耳机 |

**拍摄小技巧：**

1. **光线**：面向窗户或灯，不要背光
2. **角度**：手机和眼睛平齐
3. **背景**：干净整洁，不要太乱
4. **语速**：说慢一点，比平时说话慢 1.5 倍
5. **表情**：放松微笑，像和家人聊天

## 4. 图片内容创作

### 4.1 封面图

**用豆包生成配图描述：**

> "帮我描述一张 [你的主题] 的封面图，要：
> - 画面简洁明了
> - 文字醒目
> - 颜色鲜艳

然后用 Canva 或图司机等工具制作。

### 4.2 九宫格图片

**适合朋友圈/小红书：**

把一个主题分成 9 张图讲述：

| 第 1 张 | 第 2 张 | 第 3 张 |
|---------|---------|---------|
| 引子/悬念 | 要点 1 | 要点 2 |
| 要点 3 | 细节图 | 总结 |
| 互动问题 | 引导关注 | 感谢 |

## 5. 内容类型模板

### 5.1 经验分享型

**结构：故事 + 经验 + 总结**

```
开头：描述一个场景或问题
中间：分享你的做法/经验（3-5 条）
结尾：总结 + 互动问题
```

**示例 Prompt：**
> "帮我写一篇经验分享，主题是'我如何坚持每天早起'，结构是：故事引入 + 3 个具体方法 + 总结"

### 5.2 教程型

**结构：问题 + 步骤 + 注意事项**

```
开头：这个问题的普遍性
中间：分步骤讲解（每步不超过 3 句）
结尾：注意事项 + 鼓励
```

**示例 Prompt：**
> "帮我写一篇教程，教人如何 [你的技能]，步骤要清晰，每步不超过 50 字。"

### 5.3 故事型

**结构：背景 + 冲突 + 高潮 + 结局**

```
开头：介绍时间、地点、人物
中间：发生了什么事
高潮：最精彩/最困难的部分
结局：学到了什么
```

**示例 Prompt：**
> "帮我写一个 [300] 字的故事，关于 [你的经历]，要有情节起伏，让人想看完。"

## 6. 内容发布检查清单

发布前检查：

- [ ] 标题够吸引人吗？
- [ ] 开头 3 秒能抓住人吗？
- [ ] 有没有一个亮点让人记住？
- [ ] 有没有引导互动（评论/点赞/转发）？
- [ ] 有没有透露隐私信息（需要删掉）？
- [ ] 配图是否清晰？

## 7. 保持创作节奏

### 7.1 多久发一次？

| 阶段 | 建议频率 |
|------|----------|
| 刚起步 | 每周 1-2 条 |
| 坚持 1 个月 | 每周 2-3 条 |
| 形成习惯 | 每天 1 条 |

### 7.2 建立素材库

**每天收集素材：**

- 看到的好的内容 → 收藏
- 突然想到的点子 → 记下来
- 被问到的问题 → 记下来
- 有意思的事 → 记下来

**用豆包帮你整理：**
> "帮我把这些素材整理成几类，每类起一个标题。"

## 8. 常用 Prompt 模板

### 8.1 写文章

```
请帮我写一篇 [字数] 字的文章，主题是 [主题]。

要求：
- 开头用 [故事/问题/数据] 引入
- 中间 [3-5] 个要点
- 结尾有 [总结/号召]
- 语气：[亲切/专业/幽默]
```

### 8.2 起标题

```
请给 [主题] 起 [5] 个标题，要：
- 有悬念或数字
- 让人想点击
- 不要标题党
```

### 8.3 写口播脚本

```
请写一个 [60] 秒的口播脚本，主题是 [主题]。

要求：
- 第一句抓住注意力
- 中间 3 个要点
- 最后引导评论
- 语气像和邻居聊天
```

### 8.4 写互动问题

```
请为 [主题] 写 [3] 个互动问题，要：
- 和内容相关
- 让人想评论
- 简单易回答
```
