# IP 创作 Prompt 库

> 用 AI 帮你创作内容，复制 → 替换 → 使用

## 1. IP 定位类 Prompt

### 1.1 确定 IP 方向

```
请帮我分析我的 IP 定位：

我的情况：
- 年龄：[你的年龄]
- 退休前职业：[你的职业]
- 兴趣爱好：[你的爱好]
- 人生经验：[你最擅长的事]

请分析：
1. 我最适合做哪种类型的 IP？
2. 我的独特优势是什么？
3. 我应该聚焦哪个细分领域？
4. 给我 3 个可选的 IP 方向建议。
```

### 1.2 找准目标受众

```
我是一个 [你的身份，如：退休教师/家庭主妇/退休医生]，
我想分享 [你的主题，如：教育经验/养生心得]。

请帮我分析：
1. 谁最需要看我的内容？
2. 他们的痛点是什么？
3. 我能给他们带来什么价值？
4. 给我 3 个目标受众画像。
```

## 2. 标题创作 Prompt

### 2.1 爆款标题

```
请为 "[你的内容主题]" 起 10 个爆款标题。

要求：
- 有数字或悬念
- 让人想点击
- 不要标题党（不要虚假夸大）
- 适合 50+ 受众
```

### 2.2 朋友圈标题

```
请为 "[你的内容主题]" 起 5 个朋友圈标题。

要求：
- 30 字以内
- 轻松自然
- 让人想点赞或评论
```

### 2.3 视频标题

```
请为 "[你的视频主题]" 起 5 个抖音/视频号标题。

要求：
- 30 字以内
- 前 3 秒要有吸引力
- 可以有 #话题标签
```

## 3. 朋友圈文案 Prompt

### 3.1 日常分享

```
请帮我写一条朋友圈，分享 [你的主题]。

要求：
- 150-200 字
- 语气亲切自然，像和邻居聊天
- 开头要有画面感或场景
- 结尾要有互动问题
- 不要太正式
```

### 3.2 经验分享

```
请帮我写一条朋友圈，分享我的 [经验/心得]。

背景：[你的具体情况]

要求：
- 200 字以内
- 有具体例子或细节
- 让人觉得真实可信
- 结尾引导评论
```

### 3.3 早起打卡

```
请帮我写一条"早起打卡"朋友圈。

我的情况：
- 起床时间：[几点]
- 早起做了什么：[做什么]
- 坚持了多久：[多久]

要求：
- 100 字以内
- 积极正能量
- 鼓励别人也早起
```

### 3.4 养生分享

```
请帮我写一条养生主题的朋友圈。

主题：[如：早餐吃什么最养生]

要求：
- 150 字
- 有科学依据但不说教
- 分享我的实际经验
- 结尾问大家平时怎么吃
```

## 4. 长文章 Prompt

### 4.1 经验总结文

```
请帮我写一篇 [800-1500] 字的经验总结文章。

主题：[你的主题]

结构：
1. 开头：用一个故事或场景引入
2. 中间：[3-5] 个核心要点
3. 结尾：总结 + 行动号召

要求：
- 语气温暖有代入感
- 有具体例子
- 适合 50+ 读者
```

### 4.2 教程攻略文

```
请帮我写一篇教程攻略文章，主题是 [你的技能/方法]。

要求：
- [1000-2000] 字
- 分步骤讲解
- 每步不超过 3 句
- 适合新手
- 结尾有注意事项
```

### 4.3 人生故事文

```
请帮我写一篇人生故事文章。

故事主题：[你的故事]
字数：[800-1500] 字

结构：
1. 开头：设置悬念或冲突
2. 中间：详细叙述
3. 结尾：感悟和启示

要求：
- 有情节起伏
- 真实感人
- 让人看完有收获
```

## 5. 视频脚本 Prompt

### 5.1 口播脚本（30-60秒）

```
请写一个 [60] 秒的口播脚本。

主题：[你的主题]

结构：
1. 开头 5 秒：抓住注意力（问问题/说惊人事实）
2. 中间 45 秒：分享 [3] 个要点
3. 结尾 10 秒：总结 + 引导互动

要求：
- 像和邻居聊天
- 语速适中
- 有亲和力
```

### 5.2 口播脚本（1-3分钟）

```
请写一个 [2] 分钟的口播脚本。

主题：[你的主题]

结构：
1. 开头（15秒）：自我介绍 + 今天要分享什么
2. 主体（90秒）：[3-4] 个要点
3. 结尾（15秒）：总结 + 引导评论

要求：
- 开头要自我介绍（我是谁、多大年纪、做什么的）
- 中间要有具体例子
- 结尾要问一个问题引导评论
```

### 5.3 展示类视频脚本

```
请写一个 [2-3] 分钟的展示类视频脚本。

主题：[展示什么，如：我的书法/我做的一道菜]

结构：
1. 展示物品/成果
2. 讲解制作过程或背后的故事
3. 分享心得或技巧

要求：
- 画面和配音配合
- 每句话不超过 10 个字
- 要有字幕
```

## 6. 互动话题 Prompt

### 6.1 引导评论

```
请为 "[你的内容主题]" 写 [5] 个互动问题。

要求：
- 和内容相关
- 让人想评论
- 简单易回答（选择题或填空题）
- 不要太泛泛
```

### 6.2 征集故事

```
请帮我写一段"征集故事"的话术。

征集：[什么故事，如：你和孩子的难忘回忆]

要求：
- 100 字以内
- 说明为什么征集
- 说明会有什么好处
- 语气真诚
```

### 6.3 投票互动

```
请帮我设计一个 [2-3] 个选项的投票。

主题：[你的问题]

要求：
- 选项要有代表性
- 不要有"正确答案"
- 让大家愿意投票
```

## 7. 系列内容 Prompt

### 7.1 打造系列

```
我计划做一个 "[系列名称]" 系列，[每周/每天] 更新。

请帮我规划 [4] 期内容：

要求：
1. 每期主题不同但有关联
2. 难度递增
3. 给每期起一个标题
4. 简单描述每期内容
```

### 7.2 日更系列

```
我计划做 [7] 天的 "[主题]" 日更系列。

请帮我规划每天的内容：

要求：
- 每天一个独立主题
- 有关联性
- 适合朋友圈/短视频发布
```

## 8. 变现类 Prompt（进阶）

### 8.1 付费内容大纲

```
请帮我设计一个 "[主题]" 的付费内容大纲。

形式：[专栏/课程/电子书]
时长/篇幅：[具体]

要求：
- 有系统性
- 从入门到进阶
- 包含练习/作业
- 有价值感
```

### 8.2 合作文案

```
请帮我写一段合作文案。

我的情况：
- 我是：[你的身份]
- 我的账号：[粉丝数/影响力]
- 我能提供：[你的价值]

合作方：[对方是什么]
合作形式：[你想怎么合作]

要求：
- 突出我的价值
- 不要太卑微
- 专业但亲切
```

## 9. 安全与合规提示

### 9.1 健康话题免责

```
请在回答结尾加一句：
"以上仅供参考，具体情况请咨询专业人士。"
```

### 9.2 投资话题提醒

```
涉及投资、理财话题时，请加：
"投资有风险，本文不构成投资建议。"
```

### 9.3 隐私保护

```
创作时请注意：
- 不透露真实住址
- 不透露电话
- 不发未打码的证件
- 子女照片要打码或征得同意
```

## 10. 快速模板（直接复制用）

### 朋友圈万能开头

```
✅ 场景引入型：
"今天早上 [做某事] 的时候，突然想到..."

✅ 提问型：
"你们有没有遇到过 [问题]？我之前一直..."

✅ 数据型：
"[数字]% 的人都不知道 [这件事]，今天必须说说..."

✅ 故事型：
"上周发生了一件事，让我重新思考了..."
```

### 视频万能开场

```
✅ 自我介绍型：
"大家好，我是[名字]，今年[年龄]岁，[身份]。今天..."

✅ 提问型：
"你有没有想过，[问题]？今天我来告诉你..."

✅ 痛点型：
"[痛点]，这是不是你最烦恼的事？跟着我这样做..."

✅ 结果型：
"[惊人结果]，只需要[简单方法]..."
```

---

💡 **使用技巧**：把这些模板保存到备忘录，需要时直接复制到豆包，替换方括号内容即可。
