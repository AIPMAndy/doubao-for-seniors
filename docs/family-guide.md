# 家人协助手册

> 手把手教你怎么帮助爸妈做自己的 IP

---

## 📋 协助前准备

### 了解爸妈的情况

- 他们有什么特长或爱好？
- 他们平时喜欢聊什么话题？
- 他们会不会用智能手机？
- 他们的心理状态：愿意尝试新事物吗？

### 准备工具

- 智能手机（爸妈的）
- 网络通畅
- 纸笔（记录账号密码）

---

## 🎯 第一次协助（30分钟）

### 第1步：激发兴趣（5分钟）

**先讲一个故事：**

> "你知道吗？隔壁楼的张阿姨，退休前就是个普通家庭主妇。现在她每天发一条朋友圈，分享养生心得，粉丝都有 2000 多了。上次还有人来请教她怎么做养生药膳呢。"

**问他们：**

- "您有没有什么经验也想分享给大家？"
- "您觉得做菜/养生/养花这事，有没有什么秘诀？"

💡 **找到他们的兴奋点，这是做 IP 的动力。**

### 第2步：确定方向（10分钟）

**帮他们找到 IP 定位：**

问几个问题：
1. 您最想让别人知道的一件事是什么？
2. 您做什么经常被人夸？
3. 您退休前是做什么工作的？
4. 您每天都在做什么？

**根据回答，帮他们选择方向：**

| 回答 | 适合的 IP 类型 |
|------|----------------|
| 经常做饭被人夸 | 厨艺分享 |
| 养生很有心得 | 养生达人 |
| 喜欢养花种菜 | 园艺高手 |
| 经常旅行 | 旅行博主 |
| 带孙子有经验 | 隔代教育 |
| 写字/画画 | 艺术分享 |

### 第3步：发布第一条内容（15分钟）

**直接用豆包帮他们生成：**

打开豆包，说：
> "帮我写一条朋友圈，分享 [他们的兴趣/经验]，要亲切自然，像和邻居聊天。"

**帮他们复制发布：**

1. 复制豆包生成的内容
2. 打开微信 → 朋友圈
3. 长按相机图标 → 粘贴内容
4. 点"发表"

💡 **一定要让他们亲自点"发表"，这是他们的第一成就。**

---

## 📅 后续协助计划

### 第1周：每天发一条

- 每天帮他们生成一条内容
- 让他们自己发布
- 家人点赞、评论鼓励

### 第2周：开始拍视频（可选）

- 试着拍一条 30 秒视频
- 用豆包生成口播脚本
- 让他们对着念

### 第3周：培养习惯

- 固定发布时间（如每天早上8点）
- 开始建立素材库
- 鼓励他们自己写（可以不会写，用说的）

---

## 🛠️ 常见问题

### 问题1：他们说"我不会"

**回答：**
- "不用会，AI 会帮你写"
- "你只需要说出自己的想法就行"

**示范：**
- 打开豆包
- 让他们说一句完整的话
- 展示 AI 生成的内容

### 问题2：他们说"没人看"

**回答：**
- "先发 10 条再说"
- "先让家人关注点赞"
- "重要的是开始，不是结果"

### 问题3：他们说"怕写不好"

**回答：**
- "发出去的那一刻，你已经比 99% 的人勇敢了"
- "没人会笑话一个认真分享的人"
- "写得不好可以改，先发出去"

### 问题4：他们不知道写什么

**帮他们列清单：**

- 您每天早上做什么？
- 您最近做了什么好吃的？
- 您有什么养生小妙招？
- 您最近去了哪里？
- 您想给年轻人分享什么？

### 问题5：他们不会打字/打字慢

**解决方案：**
- 用语音输入
- 用豆包的语音功能
- 让他们说，AI 来写

## 💬 鼓励话术

### 他们成功发布时

- "太棒了！您今天正式成为创作者了！"
- "看，您写得比我还好！"
- "这条内容很好，肯定有人喜欢"

### 他们想放弃时

- "这才刚开始，不要急"
- "您的人生经验这么丰富，不分享太可惜了"
- "今天先休息，明天我们继续"

## 📱 实用工具清单

### 内容生成

- **豆包**：语音输入，自动生成文案
- **文心一言**：另一个选择
- **ChatGPT**：需要翻墙，但功能强大

### 配图

- **Canva**：做封面图，简单易用
- **图司机**：中文设计工具
- **醒图**：修图加滤镜

### 视频剪辑

- **剪映**：手机剪辑首选
- **快影**：简单易用

### 发布平台

- **微信朋友圈**：最简单
- **视频号**：微信内置
- **抖音/快手**：短视频平台

## ✅ 协助成功标志

爸妈能独立完成以下操作，就算成功了：

- [ ] 自己打开豆包/AI 工具
- [ ] 用语音说出想分享的内容
- [ ] 自己复制发布到平台
- [ ] 和评论的人互动
- [ ] 每天主动想发什么内容

## 🎁 进阶技巧

### 帮他们建立素材库

**每天收集素材：**

- 看到好的内容 → 收藏
- 突然想到的点子 → 记下来
- 被问到的问题 → 记下来
- 有意思的事 → 记下来

### 帮他们固定更新时间

- 选择一个固定时间
- 设置手机提醒
- 形成习惯

### 帮他们分析数据

- 哪些内容反响好？
- 什么话题更受欢迎？
- 调整内容方向

---

**记住：耐心是最好的协助。**

**你的鼓励，是他们坚持下去的最大动力。** 💪
