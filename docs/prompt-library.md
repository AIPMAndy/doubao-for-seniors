# IPClaw 长辈版 Prompt 库

&gt; 适配本项目的中老年学习场景 + 家人协助场景。
&gt; 使用方式：复制模板 → 替换方括号内容 → 不满意就用"追问模板"继续迭代。

## 1. 万能提问骨架（先记住这 1 套）

```text
背景：我现在在做[事情]。
目标：我希望得到[结果]。
约束：请用[字数/语气/格式]输出。
输出：请按[步骤/清单/表格]给我。
```

## 2. 中老年用户高频 Prompt（20 条）

### 2.1 生活与出行（5 条）

```text
1) 今天天气怎么样？请告诉我是否需要带伞和加衣。
2) 我想去[地点]，请给我地铁和打车两种路线。
3) 明天我要去医院复查，请给我出门前准备清单。
4) 请帮我写一条提醒家人的短信，礼貌、简短。
5) 请告诉我今天最该做的3件事，每条不超过15个字。
```

### 2.2 健康参考（5 条）

```text
1) 请用大白话解释"血压偏高"是什么意思。
2) 高血压饮食要注意什么？请给3条可执行建议。
3) 我最近睡眠不好，请给我今晚就能做的改善动作。
4) 这段体检报告请解释：哪些词需要去问医生。
5) 涉及吃药问题，请先提醒我"必须以医生建议为准"。
```

### 2.3 写作与沟通（5 条）

```text
1) 帮我写一条生日祝福，给老同学，真诚一点。
2) 帮我写一条家庭群通知，提醒周末聚餐。
3) 请写一条请假说明，原因是家人住院，请假3天。
4) 请把下面这段话改得更礼貌、容易理解。
5) 请给我3种风格：正式版、温和版、幽默版。
```

### 2.4 看图识字与翻译（5 条）

```text
1) 请先识别图中文字，再告诉我重点3条。
2) 请把这段英文翻译成中文，并告诉我什么时候用。
3) 这是药盒图片，请告诉我"作用-用法-注意事项"。
4) 这是菜单，请推荐清淡少油的选择。
5) 看完图后，请给我"重点3条+风险1条"。
```

## 3. 家人协助 Prompt（10 条）

```text
1) 请把这段内容改写成适合60岁长辈看的版本，短句、少术语。
2) 请把这个操作步骤压缩成4步，每步不超过15字。
3) 请生成"教爸妈用AI"的7天计划，每天10分钟。
4) 请给我一份"隐私三不发"提醒卡片文案。
5) 请把这个回答做成"可直接读给父母听"的口语版。
6) 请给我一个"长辈听不懂时"的追问模板。
7) 请把这条消息判断风险等级，并给核查步骤。
8) 请给我一个"每周复习清单"，适合家庭辅导。
9) 请输出家人协助记录表：日期/学会内容/卡点/下次计划。
10) 请生成一段鼓励话术，让长辈更愿意继续学。
```

## 4. IPClaw 专属 Prompt（新增）

### 4.1 本地 AI 助手配置

```text
1) 帮我配置一个长辈专属的 AI 助手，要求：
   - 说话风格：亲切、耐心、像家人
   - 回答长度：不超过200字
   - 安全提醒：涉及医疗/法律时自动提示咨询专业人士

2) 请给我的 AI 助手起一个亲切的名字，并写一段欢迎语。
```

### 4.2 技能定制

```text
3) 帮我创建一个"健康提醒"技能：
   - 每天早上8点提醒喝水、测血压
   - 每周日提醒整理本周体检数据
   - 提醒语气要温和，像子女在说话

4) 帮我创建一个"防诈骗助手"技能：
   - 收到可疑消息时帮我分析风险
   - 用大白话解释常见诈骗套路
```

## 5. 进阶追问模板（10 条）

```text
1) 请再给一个更保守、更稳妥的版本。
2) 请指出你回答里最不确定的3个点。
3) 请把答案改成表格并加优先级。
4) 请把术语替换成普通人能懂的说法。
5) 请给一个"今天就能开始"的最小方案。
6) 请给一个"预算更低"的替代方案。
7) 请给一个"风险更低"的替代方案。
8) 请把这段改成老人群里可读版本。
9) 请补充一个反例，告诉我常见误区。
10) 请最后给我一份检查清单（checkbox格式）。
```

## 6. 安全与合规提示（建议固定追加）

把下面这句作为高风险场景固定尾注：

```text
请在回答结尾加一句：以上仅供参考，涉及医疗/法律/投资等问题请咨询专业人士。
```

## 7. 与 IPClaw 生态的结合

本项目的 Prompt 可以：
- 直接在任何 AI 助手中使用（豆包、ChatGPT、Claude 等）
- 封装成 [OpenClaw](https://github.com/openclaw/openclaw) 技能，给长辈定制专属 AI 助手
- 分享到 OpenClaw 社区，帮助更多家庭
